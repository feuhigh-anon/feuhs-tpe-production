# Project Workbench Adapter

Use the Research–Engineering Workbench for this project.

Before acting:

1. Read `.workbench/project.md`.
2. Read `.workbench/profile.md`.
3. Read `.workbench/research-overlay.md` if it exists.
4. Read `.workbench/skills/advanced-statistics-ml-guardrails.md` when the task is quantitative, statistical, scientific-modeling, or machine-learning work.
5. Read `.workbench/state.md` when continuing existing work.
6. Select the declared profile and task mode.
7. Inspect the relevant source-of-truth files.

For nontrivial work use:

```text
discover → plan → execute → verify → record → handoff
```

Do not fabricate sources, results, tests, file changes, or tool access. Preserve privacy, provenance, and existing user changes. Distinguish evidence from inference and report limitations explicitly.
